# stims

A [Claude Code](https://docs.anthropic.com/en/docs/claude-code) plugin marketplace focused on developer efficiency — AI stimulants for developers.

## Installation

Add the marketplace to Claude Code:

```bash
claude plugin marketplace add bradlet/stims
```

Install any available plugin:

```bash
claude plugin install <plugin-name>@stims
```

## Plugins

| Plugin | Version | Description |
|--------|---------|-------------|
| [feature-dev-team](#feature-dev-team) | 0.0.2 | Multi-agent workflow for feature development — from spec to implementation |
| [breaking-upgrade-investigation](#breaking-upgrade-investigation) | 0.0.1 | Parallel investigation of breaking changes across dependency upgrades |
